# CMB Projekt-Cockpit

Lies zuerst [AGENTS.md](AGENTS.md) (Arbeitsregeln für KI-Assistenten) und
[DOKUMENTATION.md](DOKUMENTATION.md) (Architektur, Funktionen, Datenmodell,
Änderungsprotokoll). Beide Dateien sind verbindlich – insbesondere:

- Nutzer ist kein Programmierer → Alltagssprache, Klick-Schritte.
- Eine statische `index.html`, kein Framework, CMB-Markenkit einhalten.
- Bei **jeder** Änderung `DOKUMENTATION.md` mitpflegen (inkl. Änderungsprotokoll)
  und auf `main` pushen (Auto-Deploy via GitHub Pages).
- Öffentliches Repo: niemals Geheimnisse committen.
